# Changelog

Notable changes will be recorded here. RAGForge uses semantic versioning, with potentially breaking changes during the 0.x development phase.

## [Unreleased]

### Added
- FastAPI REST API with JWT authentication and resource ownership checks.
- Asynchronous PDF ingestion with PostgreSQL-backed jobs and ChromaDB indexing.
- Semantic retrieval, source-grounded Q&A and insufficient-context handling.
- LangGraph conversational Q&A with PostgreSQL checkpoint persistence.
- Docker Compose setup, Alembic migrations, automated tests and GitHub Actions CI.
- LangSmith evaluation workflow, architecture documentation and sample demo document.

The first planned release is v0.1.0, subject to release acceptance checks.
